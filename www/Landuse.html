NSW Landuse 2017 v1.2

 

Below is a subset of the secondary and tertiary land use classes from the NSW Landuse 2017 v1.2 data set sourced from NSW SEED.

This data represents the land use classes clipped to the NSW coastal catchments.

Tertiary classes highlighted in red are considered to be urban/developed and have been excluded from the modelled extent.

Land use classes represented on the map are the secondary level of classification.
